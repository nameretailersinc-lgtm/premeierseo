To reduce image size in KB without ruining the photo, work in this order: read the form's rules, crop, set the pixel dimensions, then compress to the byte limit. Compressing first and resizing later usually wastes quality.

## Read the form's limits before you edit

Upload forms often set up to four separate rules. Meeting one does not meet the others.

| Rule | Example | What changes it |
| --- | --- | --- |
| File size | Under 50 KB, or between 20 and 50 KB | Compression and pixel dimensions |
| Pixel dimensions | 200 × 230 pixels | Cropping and resizing |
| Print size | 3.5 × 4.5 cm at 200 DPI | Converted into pixels |
| Format | JPG only | Saving in another format |

If the form gives centimeters and DPI, the pixel size is **centimeters ÷ 2.54 × DPI**. At 200 DPI, 3.5 cm is about 276 pixels and 4.5 cm is about 354 pixels.

## Crop before you compress

A phone photo contains millions of pixels, and most of them are background in an ID-style picture. Cropping to the face or the document removes data you do not need, so more of the byte budget goes to the part that will be checked. Use the [crop tool](/free-crop-image-online/) and keep any margin the form's photo rules require.

## Compress to the target

Open [Reduce Image Size in KB](/reduce-image-size-in-kb/), type the limit, and add your image. It searches for the highest quality that fits and lowers the dimensions only if quality alone is not enough. The result row shows the exact byte count and the new dimensions.

When the form also fixes the width and height, use [Photo Resizer in KB](/photo-resizer-in-kb/), which sets pixels and a KB range in one step. For the most common single limits there are ready presets for [20KB](/compress-image-to-20kb/) and [50KB](/compress-image-to-50kb/).

## Handle a minimum size as well

Some forms reject files that are too **small**, for example "between 20 and 50 KB". A very plain image can compress below the minimum. Start again from the original, allow a higher quality, or use the required pixel dimensions if you had made the picture smaller than the form asked for. Do not enlarge a tiny image just to add bytes; it will not look sharper.

## Check the result before uploading

- Open the downloaded file and zoom to 100%.
- Names, numbers and signatures must be readable.
- Confirm the byte size, dimensions and format against the form.
- Keep the original. Each new compression of a JPG can lose a little more detail, so edit from the original every time.

If the limit cannot be reached while the photo stays readable, a smaller file is not the answer. Check whether the form accepts another format or a larger size. For choosing between formats, see [JPG vs PNG vs WebP](/blog/jpg-vs-png-vs-webp/).
