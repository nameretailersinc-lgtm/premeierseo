The safest way to reduce PDF file size depends on what is inside the file. A report exported from a word processor and a stack of scanned pages can look identical on screen, but they need different treatment.

## Find out what kind of PDF you have

Open the file and try to select a sentence with your cursor.

- **You can select words:** the pages hold real text. The size usually comes from photos or embedded graphics.
- **You can only drag a box:** each page is an image, typically a scan or phone photo. Page images are the size.
- **Mixed:** some pages are text and some are scans.

## Choose a method

| Method | Keeps selectable text | Best for | Main risk |
| --- | --- | --- | --- |
| Clean up and repack the file | Yes | Text documents and forms | Savings can be small |
| Recompress the images inside | Yes | Reports with photos | Photos look softer |
| Turn pages into images | No | Scans with a strict limit | Text can no longer be searched or copied |

Try the methods in that order. Stop at the first one that meets your limit and still reads well.

[Compress PDF](/compress-pdf/) offers these as **Keep text**, **Smallest size** and **Target size**. Target size tries to keep the text first. If it has to convert pages into images to reach your limit, it says so. If even the lowest setting is too large, it reports the smallest result instead of claiming success.

![The PDF compressor set to a target size, with quick limits from 100 KB to 2 MB](/blog-images/reduce-pdf-file-size-example.jpg "Target size works toward an upload limit and tells you how the result was produced.")

## Shrink the content before you compress

Often the biggest saving is removing what the recipient does not need.

1. Use [Split PDF](/split-pdf/) to keep only the required pages.
2. If you can re-scan, choose grayscale for black-and-white paperwork and a moderate resolution.
3. If you still have the source document, resize oversized pictures there and export again.

## Work to an upload limit

Check whether the limit applies to one file or to all attachments together. The page count matters: ten scanned pages sharing 200KB get about 20KB each, which is rarely enough for small print. There are presets for [100KB](/compress-pdf-to-100kb/), [200KB](/compress-pdf-to-200kb/) and [1MB](/compress-pdf-to-1mb/).

## Check before you send

- Zoom into the smallest text, stamps, signatures and reference numbers.
- Check every page, not only the first one.
- Test links, bookmarks and fillable fields if the document needs them.
- Keep the original. A converted copy cannot be turned back into it.

A signed or certified PDF can lose its signature validity when it is rewritten. If the signature matters, ask the recipient for another way to send the file instead of compressing it.

If you are assembling several files first, see [how to merge PDF files on a phone](/blog/how-to-merge-pdf-files-on-phone/) and compress once, after merging.
